# TG Knowledge Bot

Telegram group knowledge base builder. Connects to a Telegram group via your personal account (MTProto), analyzes messages, builds a searchable knowledge base with deduplication and quality scoring based on user reputation and answer completeness.

## Architecture

```
Telegram Group (~3K users)
       │
       ▼  MTProto (gramjs)
  Ingestor ──► SQLite (messages)
       │
       ▼  async queue
  Analyzer Pipeline:
    ├── Classify (question/answer/discussion/noise)
    ├── Embed (vector via AI SDK)
    ├── Quality Score (LLM + user reputation + community signals)
    └── Dedup (cosine similarity → merge or create KB entry)
       │
       ▼
  Knowledge Base (SQLite)
       │
       ▼
  Query Interface (interactive /ask)
```

## Quick Start

```bash
# 1. Clone and install
git clone https://github.com/kilogramirisok/tg-knowledge-bot.git
cd tg-knowledge-bot
npm install

# 2. Configure
cp .env.example .env
# Edit .env with your credentials

# 3. Generate Telegram session (requires API keys from https://my.telegram.org)
npm run auth

# 4. Test with seed data (no Telegram connection needed)
npm run seed    # populate test messages
npm run analyze # run analysis pipeline
npm run query   # interactive query interface

# 5. Production: connect to real group
npm run dev -- --mode=all
```

## Modes

| Mode | Description |
|------|-------------|
| `--mode=seed` | Populate DB with test data (Spanish tax/nomad messages) |
| `--mode=analyze` | Process all unprocessed messages through the pipeline |
| `--mode=reputation` | Recalculate user reputation scores |
| `--mode=query` | Interactive terminal query interface |
| `--mode=ingest` | Start MTProto ingestor only (reads from Telegram) |
| `--mode=all` | Run all services (ingest + analyze loop + reputation cron) |

## Environment Variables

| Variable | Required | Description |
|----------|----------|-------------|
| `TELEGRAM_API_ID` | For ingest | From https://my.telegram.org |
| `TELEGRAM_API_HASH` | For ingest | From https://my.telegram.org |
| `TELEGRAM_SESSION` | For ingest | Generated by `npm run auth` |
| `TARGET_GROUP` | No | Group username (default: `taxesnomadspain`) |
| `GOOGLE_GENERATIVE_AI_API_KEY` | For LLM | Google AI API key (Gemini) |
| `OPENAI_API_KEY` | Alternative | OpenAI API key (alternative to Google) |
| `DATABASE_PATH` | No | SQLite path (default: `./data/knowledge.db`) |

## Tech Stack

- **TypeScript** + Node.js 24
- **Vercel AI SDK** — LLM calls (classification, quality scoring, query synthesis)
- **gramjs** (`telegram`) — MTProto client for reading group messages via personal account
- **Drizzle ORM** + **better-sqlite3** — database
- **Vector similarity** — embeddings stored as JSON, brute-force cosine similarity

## Scoring System

### KB Inclusion Score
```
final = 0.30 × answer_quality       (LLM-judged completeness)
      + 0.25 × user_reputation      (activity + expertise + curation rate)
      + 0.20 × community_signal     (reactions received)
      + 0.15 × recency              (exponential decay, 30-day half-life)
      + 0.10 × source_diversity     (multiple contributors)
```

### Deduplication
- Embeddings compared via cosine similarity
- `> 0.92`: merge (keep higher-scoring version)
- `0.85 - 0.92`: link as related
- `< 0.85`: new KB entry

### User Reputation
```
reputation = 0.30 × activity_consistency
           + 0.25 × expertise_signals (reactions on answers)
           + 0.25 × curation_rate     (answers accepted into KB)
           + 0.20 × recency           (7-day half-life)
```
